# Iterative Model Collapse Experiment

This experiment studies **model collapse** in Probabilistic Flow Networks (PFNs) when training data is replaced with model-generated synthetic data during training.

## Hypothesis

Training a PFN on its own generated synthetic data (instead of true GP data) will lead to progressive model collapse, characterized by:
- Increased test loss on true GP tasks
- Reduced prediction diversity
- Degraded uncertainty calibration
- Loss of distributional properties

## Experimental Setup

### Training Procedure

1. **Phase 1 (Epochs 1 to N)**: Train PFN on true GP data
2. **Phase 2 (Epochs N+1 to M)**: Continue training the SAME model on synthetic data generated by itself
3. **Evaluation**: Continuously evaluate on a fixed true GP test set

### Key Innovation

Unlike multi-generation approaches, this is a **single continuous training run** where the data source switches mid-training. This simulates real-world scenarios where model-generated data pollutes the training distribution.

## Quick Start

### 1. Quick CPU Test (Recommended First)

Test that everything works with a small, fast experiment:

```bash
cd experiments/iterative_collapse

# Quick test: 20 epochs, switch at epoch 10 (~30-60 min on CPU)
python train_with_switch.py \
    --experiment_name quick_test \
    --switch_epoch 10 \
    --total_epochs 20 \
    --batch_size 200 \
    --steps_per_epoch 10 \
    --emsize 256 \
    --nlayers 3 \
    --nhid 512
```

### 2. Full Experiment (GPU Recommended)

Run the full experiment (2-4 hours on GPU, 30-50+ hours on CPU):

```bash
# Using config file
python train_with_switch.py --config config.yaml

# Or specify parameters directly
python train_with_switch.py \
    --experiment_name full_collapse_experiment \
    --switch_epoch 100 \
    --total_epochs 200 \
    --prior gp \
    --synthetic_mode sample \
    --batch_size 1000 \
    --emsize 512 \
    --nlayers 6
```

### 3. Visualize Results

```bash
# Create plots from metrics
python visualize.py \
    --metrics_file ./metrics/<experiment_name>_metrics.json \
    --output_dir ./plots

# The following plots will be generated:
# - loss plot: Training vs test loss over time
# - variance plot: Prediction uncertainty evolution
# - learning rate plot: LR schedule
# - combined plot: All metrics in one figure
# - collapse summary: Before/after switch analysis
```

## Experimental Variants

### Variant 1: Early vs. Late Switch

Test when the switch happens:

```bash
# Early switch (model undertrained)
python train_with_switch.py --switch_epoch 50 --total_epochs 200

# Late switch (model well-trained)
python train_with_switch.py --switch_epoch 150 --total_epochs 200
```

### Variant 2: Mean vs. Sampling

Test different synthetic data generation strategies:

```bash
# Use mean predictions only (faster collapse expected)
python train_with_switch.py --synthetic_mode mean

# Sample from predictive distribution (more diversity)
python train_with_switch.py --synthetic_mode sample
```

### Variant 3: Mixed Data

Test partial synthetic data:

```bash
# 50% real, 50% synthetic
python train_with_switch.py --synthetic_ratio 0.5

# 10% real, 90% synthetic
python train_with_switch.py --synthetic_ratio 0.9
```

### Variant 4: Different Priors

Test with different data sources:

```bash
# Gaussian Process (default)
python train_with_switch.py --prior gp

# GP Mixture (more flexible)
python train_with_switch.py --prior mix_gp

# Ridge regression
python train_with_switch.py --prior ridge
```

## Configuration Options

### Command-Line Arguments

| Argument | Default | Description |
|----------|---------|-------------|
| `--experiment_name` | Auto | Experiment identifier |
| `--switch_epoch` | 100 | Epoch to switch to synthetic data |
| `--total_epochs` | 200 | Total training epochs |
| `--synthetic_mode` | sample | 'mean' or 'sample' |
| `--synthetic_ratio` | 1.0 | Ratio of synthetic data (1.0 = pure) |
| `--prior` | gp | Data source: gp, mix_gp, ridge, stroke |
| `--loss_function` | gaussnll | Loss function |
| `--batch_size` | 1000 | Batch size |
| `--emsize` | 512 | Embedding dimension |
| `--nlayers` | 6 | Transformer layers |
| `--nhead` | 4 | Attention heads |
| `--lr` | 0.001 | Learning rate |

See `config.yaml` for full list of parameters.

### Using Config Files

Create a custom config file:

```yaml
# my_experiment.yaml
experiment_name: my_collapse_test
switch_epoch: 75
total_epochs: 150
synthetic_mode: sample
batch_size: 500
emsize: 256
nlayers: 4
```

Run with:

```bash
python train_with_switch.py --config my_experiment.yaml
```

You can also override config file settings:

```bash
python train_with_switch.py --config config.yaml --switch_epoch 120
```

```
| epoch  50/200 | time: 42.35s | source: true_gp      | train loss 0.234 | test loss 0.245 | lr 0.001000
| epoch  99/200 | time: 41.89s | source: true_gp      | train loss 0.145 | test loss 0.152 | lr 0.000856

!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!
!!! SWITCHING TO SYNTHETIC DATA AT EPOCH 100 !!!
!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!

| epoch 100/200 | time: 45.12s | source: synthetic    | train loss 0.143 | test loss 0.155 | lr 0.000845
| epoch 101/200 | time: 44.98s | source: synthetic    | train loss 0.138 | test loss 0.168 | lr 0.000834
```

**Key things to watch:**
- **Test loss (true GP)**: Should stay low before switch, may increase after
- **Source**: Shows whether using 'true_gp' or 'synthetic' data
- Checkpoints saved every 10 epochs

A JSON file is saved with all metrics:


## Interpreting Results

### Signs of Model Collapse

1. **Test loss divergence**: Test loss on true GP increases after switch
2. **Variance reduction**: Prediction variance decreases (overconfidence)
3. **Loss gap**: Growing gap between train and test loss
4. **Calibration degradation**: Uncertainty estimates become miscalibrated

### Positive Control (No Collapse)

If test loss continues to improve after switch, either:
- Model hasn't collapsed (good synthetic data generation)
- Need longer training to see collapse
- Model was still undertrained at switch point

### Expected Timeline

Based on similar experiments in literature:
- **Epochs 1-100**: Normal training, test loss decreases
- **Epoch 100**: Switch to synthetic data
- **Epochs 100-120**: Subtle degradation begins
- **Epochs 120-150**: Clear collapse signal
- **Epochs 150-200**: Severe collapse (if occurring)

## Troubleshooting

### Out of Memory

Reduce batch size or model size:

```bash
python train_with_switch.py --batch_size 200 --emsize 256 --nlayers 3
```

### Slow Training

- Use GPU if available (10-15x speedup)
- Reduce total_epochs for testing
- Use smaller model (--emsize 256 --nlayers 3)

### No Collapse Observed

Try:
- Earlier switch (--switch_epoch 50)
- Mean mode (--synthetic_mode mean) - faster collapse
- Longer training (--total_epochs 300)
- Check that test_loss_true is truly on true GP data

### Import Errors

Make sure you're running from the experiments/iterative_collapse/ directory, or the parent model_collapse/ directory:

```bash
cd /path/to/model_collapse
python experiments/iterative_collapse/train_with_switch.py ...
```
