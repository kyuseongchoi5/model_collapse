================================================================================
ROOT CAUSE ANALYSIS
================================================================================

1. CLASSIC MODEL COLLAPSE:
   • Synthetic data lacks the diversity of true GP samples
   • Model trains on increasingly biased synthetic distribution
   • Progressive loss of ability to generalize to true data

2. GAUSSIANNLL EXPLOITATION:
   • GaussianNLL = 0.5 * (log(var) + (y - mean)²/var)
   • Model learns to predict var → 0 to minimize loss
   • Creates feedback loop:
     Step 1: Model predicts tiny variance
     Step 2: Generates synthetic data matching those predictions
     Step 3: Training loss becomes negative (looks good!)
     Step 4: But test performance catastrophically fails

3. MODE COLLAPSE:
   • Prediction variance drops from 0.21 to 0.0003 (99.85% reduction)
   • Model outputs essentially deterministic predictions
   • Lost all uncertainty quantification capability

4. COMPLETE INSTABILITY:
   • Test loss oscillates wildly (0.6 → 479.7 → 9.4)
   • No convergence, pure chaos
   • Model is completely broken

CONCLUSIONS
================================================================================

SEVERITY: 🔴 CATASTROPHIC MODEL COLLAPSE

This experiment demonstrates:
✅ Perfect example of model collapse in action
✅ Shows how synthetic data feedback creates instability
✅ Reveals pathology specific to GaussianNLL loss
✅ Documents complete mode collapse (variance → 0)

The model went from:
  • Epoch 100: Functional GP regression (test loss 0.60)
  • Epoch 200: Completely broken (test loss 305, variance ≈ 0)

RECOMMENDATION FOR FUTURE EXPERIMENTS:
1. Try different loss functions (MSE instead of GaussianNLL)
2. Add variance regularization to prevent collapse
3. Mix real and synthetic data (synthetic_ratio < 1.0)
4. Use temperature sampling to increase diversity
5. Early stopping when variance drops below threshold

model collapse - it's a complete, textbook demonstration! 🎯
